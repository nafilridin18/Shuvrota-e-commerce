# 🛍️ শুভ্রতা (Shuvrota) ই-কমার্স প্ল্যাটফর্ম

**শুভ্রতা (Shuvrota)** — রেডি-টু-ওয়্যার শাড়ি এবং কুর্তির অনলাইন শপের জন্য একটি রেসপন্সিভ এবং আধুনিক ই-কমার্স ওয়েব অ্যাপ্লিকেশন। 

এই প্ল্যাটফর্মের মাধ্যমে কাস্টমাররা প্রোডাক্ট ব্রাউজ, কার্টে যোগ করা, ক্যাশ অন ডেলিভারিতে (COD) অর্ডার করা এবং অর্ডার ট্র্যাক করতে পারবেন। পাশাপাশি অ্যাডমিন প্যানেল থেকে সমস্ত প্রোডাক্ট এবং অর্ডার পরিচালনা করা যাবে।

---

## 🚀 প্রধান ফিচারসমূহ

### 🛒 কাস্টমার ফিচার (Storefront)
* **ডাইনামিক হোম ও ক্যাটালগ:** লাইভ সার্চ এবং ক্যাটাগরি ফিল্টারিংয়ের মাধ্যমে সহজে শাড়ি ও কুর্তি খোঁজার সুবিধা।
* **প্রোডাক্ট ডিটেইলস:** দাম, সাইজ, কালার, স্টক স্ট্যাটাস এবং ছবি দেখার ব্যবস্থা।
* **শপিং কার্ট ও চেকআউট:** ইন্টারঅ্যাক্টিভ কার্ট এবং ক্যাশ অন ডেলিভারি (COD) অর্ডার সুবিধা (ঢাকা ও ঢাকার বাইরে ক্যাটাগরি অনুযায়ী ডেলিভারি চার্জ সহ)।
* **অর্ডার ট্র্যাকিং:** ইউনিক অর্ডার আইডি (Order ID) বা ফোন নম্বর দিয়ে লাইভ অর্ডার স্ট্যাটাস ট্র্যাকিং।
* **হোয়াটসঅ্যাপ সাপোর্ট:** সরাসরি অ্যাডমিনের সাথে যোগাযোগের জন্য ভাসমান (Floating) হোয়াটসঅ্যাপ বাটন।

### ⚙️ অ্যাডমিন প্যানেল ফিচার (Admin Panel)
* **সেলস ড্যাশবোর্ড:** মোট অর্ডার সংখ্যা, নতুন পেন্ডিং অর্ডার এবং ডেলিভারি হওয়া আয়ের সামারি।
* **ক্যাটালগ ম্যানেজমেন্ট:** নতুন প্রোডাক্ট যোগ করা, এডিট করা, দাম ও স্টক পরিবর্তন করার সুবিধা।
* **অর্ডার ম্যানেজমেন্ট:** কাস্টমারের অর্ডার তালিকা দেখা এবং স্ট্যাটাস পরিবর্তন করা (*New, Processing, Delivered, Cancelled*)।

## 🛠️ ব্যবহৃত প্রযুক্তি (Tech Stack)

* **ব্যাকএন্ড:** PHP 8.x (PDO, Session API)
* **ফ্রন্টএন্ড:** HTML5, CSS3, JavaScript, Bootstrap 5, FontAwesome 6
* **ডাটাবেজ:** MySQL
* **ভার্সন কন্ট্রোল:** Git & GitHub
